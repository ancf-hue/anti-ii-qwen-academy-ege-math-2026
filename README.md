  # Анти-ИИ Qwen Академия | Математика ЕГЭ-2026

**Бесплатный офлайн-тренажёр и чек-лист подготовки к ЕГЭ по математике 2026.**

Проект помогает подготовиться к базовому и профильному уровням ЕГЭ по математике, разобраться в структуре экзамена, повторить ключевые темы и научиться проверять решения, а не слепо копировать ответы.

---

## О проекте

«Анти-ИИ Qwen Академия | Математика ЕГЭ-2026» — это одностраничное веб-приложение для самостоятельной подготовки к экзамену.

Главная идея проекта — **анти-ИИ подход**:  
готовые решения, полученные с помощью искусственного интеллекта, часто содержат вычислительные ошибки, неверные формулы и пропущенные шаги. Поэтому важно учиться проверять каждое действие, понимать логику решения и самостоятельно находить ошибки.

Приложение подходит:

— школьникам 10–11 классов;  
— абитуриентам;  
— преподавателям математики;  
— репетиторам;  
— родителям, помогающим с подготовкой.

---

## Основные возможности

### Структура ЕГЭ-2026

В проекте отражена актуальная структура:

— **Базовый уровень:** 21 задание с кратким ответом;  
— **Профильный уровень:** 19 заданий, из них 12 с кратким ответом и 7 с развёрнутым решением.

### Интерактивный тренажёр

Тренажёр включает автоматические вопросы для:

— базового уровня;  
— профильного уровня, часть 1.

Для каждого задания используется формат:

1. **Вопрос**  
2. **Информация о задании**  
3. **Тренажёр**

Варианты ответов перемешиваются, чтобы нельзя было запомнить позицию правильного ответа. Правильный ответ и пояснение показываются только после ответа пользователя.

### Задания с графикой

В проект встроены SVG-изображения:

— графики продаж;  
— план местности на клетчатой бумаге;  
— координатная прямая;  
— векторы на координатной плоскости;  
— график производной;  
— парабола квадратичной функции.

Это позволяет работать с заданиями прямо в браузере, без отдельных PDF-файлов.

### Часть 2 профильного уровня

Задания 13–19 не проверяются автоматически по одному финальному ответу, потому что требуют полного обоснованного решения.

Для них предусмотрены:

— условия заданий;  
— методические подсказки;  
— ориентировочные ответы там, где это корректно;  
— поле для самопроверки.

### Чек-лист подготовки

Чек-лист помогает системно пройти основные темы:

— формулы сокращённого умножения;  
— степени и логарифмы;  
— площади фигур;  
— теорема Пифагора;  
— тригонометрия;  
— квадратные уравнения;  
— текстовые задачи;  
— вероятность;  
— стереометрия;  
— производная;  
— оформление развёрнутых решений.

### План подготовки на 25 дней

Проект содержит маршрут подготовки для 11 класса:

— диагностика;  
— алгебра;  
— уравнения и неравенства;  
— функции и графики;  
— производная;  
— текстовые задачи;  
— вероятность и статистика;  
— планиметрия;  
— стереометрия;  
— векторы;  
— логарифмы;  
— тригонометрия;  
— задания профильной части 1;  
— задания 13–19;  
— пробные варианты;  
— финальный разбор ошибок.

### Переключение языка RU/EN

Интерфейс поддерживает два языка:

— русский;  
— английский.

Кнопка переключения языка находится в правом верхнем углу.

### Экзаменационный таймер

В правом верхнем углу также расположен таймер с пресетами:

— базовый уровень: 180 минут;  
— профильный уровень: 235 минут;  
— тренировка: 60 минут.

Таймер имеет кнопки запуска, паузы и сброса, а также визуальные предупреждения при остатке менее 5 минут и менее 1 минуты.

Философия проекта: Анти-ИИ

Проект не запрещает использовать технологии. Он учит критически относиться к автоматическим ответам.

ИИ может помочь объяснить тему, но не должен заменять понимание. На ЕГЭ важно уметь:

— читать условие;

— проверять каждое действие;

— контролировать знаки;

— проверять область допустимых значений;

— оценивать правдоподобность ответа;

— оформлять развёрнутое решение по критериям.


Важное примечание

Минимальные пороги, распределение баллов и официальные требования необходимо сверять с актуальными материалами ФИПИ и

приказами Рособрнадзора на 2026 год.

Проект носит учебно-тренировочный характер и помогает структурировать подготовку.
